============
Installation
============

This a pure Python implementation of Natnet with minimal external dependencies.

To install the library and the CLI utilities:

.. code-block:: bash

   pip install git+https://github.com/jeguzzi/natnet_py.git


To run the web-based GUI or to save data to H5DF, add `[all]`:

.. code-block:: bash

   pip install git+https://github.com/jeguzzi/natnet_py.git[all]
